## 四、实验步骤

### 第一部分：关联分析

#### 步骤 1：数据加载与预处理

```python
# 加载菜品订单数据
df = pd.read_excel('data/menu_orders.xls', header=None)

# 转换为事务列表
transactions = []
for _, row in df.iterrows():
    transaction = [item for item in row if pd.notna(item)]
    transactions.append(transaction)
```

**输出结果**：成功加载 10 条事务记录

#### 步骤 2：转换为 0-1 矩阵

```python
# 使用 TransactionEncoder 进行独热编码
te = TransactionEncoder()
te_array = te.fit(transactions).transform(transactions)
df_encoded = pd.DataFrame(te_array, columns=te.columns_)
```

**输出结果**：
- 生成 10×5 的 0-1 矩阵
- 5 个菜品：a, b, c, d, e

#### 步骤 3：挖掘频繁项集

```python
# 使用 Apriori 算法，最小支持度 = 0.3
frequent_itemsets = apriori(df_encoded, min_support=0.3, use_colnames=True)
```

**参数设置**：
- 最小支持度（min_support）：0.3

**输出结果**：发现 11 个频繁项集

#### 步骤 4：生成关联规则

```python
# 生成关联规则，最小置信度 = 0.6
rules = association_rules(frequent_itemsets, metric="confidence", min_threshold=0.6)
```

**参数设置**：
- 最小置信度（min_confidence）：0.6

**输出结果**：生成 15 条关联规则

### 第二部分：离群点检测

#### 步骤 1：加载消费数据

```python
df = pd.read_excel('data/consumption_data.xls')
```

**输出结果**：成功加载 940 条客户记录

#### 步骤 2：数据标准化

```python
# 使用 StandardScaler 进行标准化
features = ['R', 'F', 'M']
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df[features])
```

**标准化公式**：z = (x - μ) / σ

**输出结果**：
- 标准化后各特征均值为 0，标准差为 1

#### 步骤 3：K-Means 聚类

```python
# 使用 K-Means 算法，K=3
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
df['Cluster'] = kmeans.fit_predict(X_scaled)
```

**参数设置**：
- 聚类数量（K）：3
- 随机种子：42

**输出结果**：

| 簇 | 样本数量 | 占比 |
|----|----------|------|
| 0  | 40       | 4.3% |
| 1  | 340      | 36.2% |
| 2  | 560      | 59.6% |

**聚类中心（原始尺度）**：

| 簇 | R（天） | F（次） | M（元） |
|----|---------|---------|---------|
| 0  | 63.10   | 7.45    | 1383.04 |
| 1  | 14.56   | 17.80   | 1344.72 |
| 2  | 14.76   | 4.80    | 866.88  |

#### 步骤 4：计算到聚类中心的距离

```python
# 计算每个样本到所属聚类中心的欧氏距离
for i in range(len(X_scaled)):
    cluster_id = int(df.iloc[i]['Cluster'])
    center = kmeans.cluster_centers_[cluster_id]
    dist = np.sqrt(np.sum((X_scaled[i] - center) ** 2))
    distances.append(dist)
```

**距离统计**：
- 平均距离：1.1217
- 标准差：0.6236
- 最大距离：9.1087

#### 步骤 5：离群点检测

```python
# 使用均值 + 2倍标准差作为阈值
threshold = df['Distance'].mean() + 2.0 * df['Distance'].std()
df['Is_Outlier'] = df['Distance'] > threshold
```

**参数设置**：
- 阈值倍数：2.0
- 计算阈值：2.3689

**输出结果**：
- 检测到 11 个离群点
- 离群点占比：1.2%

## 六、技术要点总结

### 6.1 Apriori 算法
- **核心思想**：通过逐层搜索发现频繁项集
- **关键参数**：支持度（support）、置信度（confidence）、提升度（lift）
- **应用场景**：购物篮分析、交叉销售推荐

### 6.2 K-Means 聚类
- **核心思想**：将数据划分为 K 个簇，最小化簇内距离
- **关键步骤**：标准化 → 聚类 → 距离计算 → 阈值筛选
- **离群点定义**：到聚类中心距离超过阈值的样本

### 6.3 数据标准化
- **目的**：消除不同特征的量纲差异
- **方法**：Z-score 标准化（均值为 0，标准差为 1）
- **重要性**：距离计算对尺度敏感，必须标准化
