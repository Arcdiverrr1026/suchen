# 实验3实验报告正文

## 一、实验名称
聚类分析与关联分析

## 二、实验目的
1. 熟练掌握 K-Means 聚类算法的原理与实现方法，能够通过该算法对消费数据进行分群。
2. 理解聚类中心、类别数量的统计意义，并结合 t-SNE 降维可视化结果解读数据的潜在分布规律。
3. 理解关联规则挖掘的核心思想，掌握 Apriori 算法的工作流程。
4. 能够基于菜品订单数据挖掘高频项集与强关联规则，分析消费场景中的关联消费模式。

## 三、实验环境
- 操作系统：macOS
- Python 版本：Python 3
- 虚拟环境：`.venv`
- 主要库：`pandas`、`numpy`、`scikit-learn`、`mlxtend`、`matplotlib`、`xlrd`

## 四、实验内容
1. 对消费数据进行标准化处理，使用 K-Means 算法将数据聚为 3 类，统计聚类中心与类别数量，输出聚类结果，并用 t-SNE 对结果进行降维展示。
2. 读取菜品订单数据并转换为 0-1 矩阵形式的事务数据集；调用 Apriori 算法，设置支持度、置信度阈值，挖掘菜品间的关联规则；输出并筛选有业务价值的菜品搭配规则。

## 五、实验步骤与结果

### 5.1 消费数据聚类分析

#### 1. 数据读取与预处理
实验读取 `consumption_data.xls` 中的 `Sheet1` 工作表，数据字段为 `ID、R、F、M`。其中：
- `R` 表示最近一次消费间隔
- `F` 表示消费频次
- `M` 表示消费金额

由于三个特征的量纲不同，因此先使用 `StandardScaler` 对数据进行标准化处理，避免某一维特征对聚类结果产生过大影响。

#### 2. K-Means 聚类
实验中设置聚类数 `K=3`，调用 `KMeans(n_clusters=3)` 对标准化后的消费数据进行聚类，并得到每个样本所属类别。

#### 3. 聚类结果
三类用户的聚类中心如下表所示：

| cluster | R | F | M |
| --- | --- | --- | --- |
| 0 | 63.10 | 7.45 | 1383.04 |
| 1 | 14.56 | 17.80 | 1344.72 |
| 2 | 14.76 | 4.80 | 866.88 |

各类别样本数量如下：

| cluster | count |
| --- | --- |
| 0 | 40 |
| 1 | 340 |
| 2 | 560 |

#### 4. 聚类结果分析
- 第 0 类用户的 `R` 值明显偏高，说明距离最近一次消费时间较长，虽然消费金额较高，但活跃度较低，可视为沉默客户或流失风险客户。
- 第 1 类用户的 `F` 和 `M` 都较高，且 `R` 较低，说明近期消费频繁、消费金额较大，属于高价值高频客户。
- 第 2 类用户的 `R` 较低，但 `F` 和 `M` 相对较低，说明仍然活跃，但消费能力和消费频率较弱，属于普通活跃客户。

#### 5. t-SNE 可视化
为了更直观地展示聚类效果，实验进一步对标准化后的 `RFM` 数据进行 t-SNE 二维降维，并绘制散点图。结果图保存在：

`outputs/kmeans_tsne.png`

从可视化结果可以看出，不同类别样本在二维空间中具有一定区分度，说明 K-Means 聚类结果具有一定合理性。

### 5.2 菜品订单关联规则分析

#### 1. 数据读取与事务构造
实验读取 `menu_orders.xls`，按“每一行表示一笔订单、每个非空单元格表示一个菜品”的方式构造事务数据。清洗后共得到 10 笔事务，涉及菜品：

`a、b、c、d、e`

然后将事务数据转换为 0-1 矩阵，为 Apriori 挖掘做准备。

#### 2. Apriori 参数设置
- 最小支持度：`min_support = 0.2`
- 最小置信度：`min_confidence = 0.6`

在此基础上挖掘频繁项集和关联规则，并结合 `lift > 1` 对规则进行筛选。

#### 3. 部分频繁项集结果

| support | itemsets | itemset_size |
| --- | --- | --- |
| 0.8 | b | 1 |
| 0.7 | a | 1 |
| 0.7 | c | 1 |
| 0.5 | a, b | 2 |
| 0.5 | a, c | 2 |
| 0.5 | b, c | 2 |
| 0.3 | e | 1 |
| 0.3 | a, e | 2 |
| 0.3 | c, e | 2 |
| 0.3 | a, b, c | 3 |

从结果可以看出，`a、b、c` 是出现频率较高的菜品，其中 `a,b`、`a,c`、`b,c` 等组合也有较高支持度。

#### 4. 关联规则结果
筛选后的典型规则如下：

| antecedents | consequents | support | confidence | lift |
| --- | --- | --- | --- | --- |
| e | a, c | 0.3 | 1.0 | 2.0 |
| a, c | e | 0.3 | 0.6 | 2.0 |
| e | a | 0.3 | 1.0 | 1.4286 |
| e | c | 0.3 | 1.0 | 1.4286 |
| d | b | 0.2 | 1.0 | 1.25 |

#### 5. 关联规则分析
- 规则 `e -> a,c` 的置信度为 1.0，提升度为 2.0，说明当菜品 `e` 出现时，菜品 `a` 和 `c` 同时出现的可能性很高，这种组合具有较强关联性。
- 规则 `d -> b` 的置信度为 1.0，说明点 `d` 的顾客总会同时点 `b`，可以考虑将两者进行套餐推荐。
- 规则 `a -> c` 与 `c -> a` 的提升度略大于 1，说明二者存在一定正向关联，但强度相对较弱。

因此，在实际业务中可以将强关联菜品设置为套餐、组合推荐或在点单页面中进行联动展示，以提高客单价和转化率。

## 六、实验结论
本次实验完成了消费数据的聚类分析和菜品订单的关联规则挖掘。通过 K-Means 聚类可以将用户划分为不同价值层次的群体，从而为精准营销和客户运营提供依据；通过 Apriori 关联规则分析可以发现菜品之间的搭配关系，为套餐设计和推荐系统提供支持。

实验结果表明：
1. 消费数据适合使用 `RFM + K-Means` 的方式进行客户分群。
2. t-SNE 降维可以较直观地展示聚类后的数据分布情况。
3. Apriori 算法能够有效挖掘订单中的高频搭配关系。
4. 由于订单样本数较少，本次关联规则结果更适合用于算法演示，不宜直接用于真实商业决策。

## 七、实验总结
在本次实验中，我进一步掌握了 K-Means 聚类和 Apriori 关联规则挖掘的基本流程，理解了标准化处理、聚类中心分析、支持度、置信度和提升度等关键概念。实验过程中，通过对消费数据和订单数据的实际操作，我加深了对数据挖掘方法在用户分群和商品推荐中的应用理解。

同时我也认识到，数据量和数据质量会直接影响分析结果的可靠性。今后在实际应用中，还需要结合更大规模的数据集、更多业务特征以及更严格的模型评估方法，才能得到更稳定、更有价值的分析结论。
