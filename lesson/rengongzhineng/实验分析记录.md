# 实验四：A* 搜索算法行为变化分析

## 1. 实验说明

- 题目要求：修改图结构或启发函数，观察 A* 算法行为变化并分析原因。
- 本次选择：**修改启发函数**，图结构保持不变。
- 起点：`A`
- 终点：`E`

原始图结构：

```python
{
    "A": [("B", 1), ("C", 4)],
    "B": [("A", 1), ("C", 2), ("D", 5)],
    "C": [("A", 4), ("B", 2), ("D", 1)],
    "D": [("B", 5), ("C", 1), ("E", 3)],
    "E": [("D", 3)],
}
```

## 2. 启发函数设置

原始启发函数：

```python
{"A": 6, "B": 5, "C": 5, "D": 2, "E": 0}
```

修改后启发函数：

```python
{"A": 6, "B": 7, "C": 2, "D": 1, "E": 0}
```

修改思路：

- 增大 `B` 的启发值，使算法认为经过 `B` 的前景较差。
- 减小 `C`、`D` 的启发值，使算法更倾向于优先沿 `A -> C -> D` 方向搜索。

## 3. 原始启发函数下的搜索过程

最终结果：

- 路径：`A -> B -> C -> D -> E`
- 总代价：`7`
- 扩展顺序：`A -> B -> C -> D -> E`

Open / Close 表变化：

| 步骤 | 当前扩展节点 | Open 表 | Close 表 |
| --- | --- | --- | --- |
| 1 | A | [B(f=6, g=1), C(f=9, g=4)] | [A] |
| 2 | B | [C(f=8, g=3), D(f=8, g=6), C(f=9, g=3)] | [A, B] |
| 3 | C | [D(f=6, g=4), D(f=8, g=4), C(f=9, g=3)] | [A, B, C] |
| 4 | D | [E(f=7, g=7), D(f=8, g=4), C(f=9, g=3)] | [A, B, C, D] |
| 5 | E | [D(f=8, g=4), C(f=9, g=3)] | [A, B, C, D, E] |

现象：

- 算法先扩展 `B`，再修正 `C` 的代价。
- 最终找到总代价为 `7` 的最优路径。
- 说明原始启发函数虽然不完全精确，但能较好引导搜索方向。

## 4. 修改后启发函数下的搜索过程

最终结果：

- 路径：`A -> C -> D -> E`
- 总代价：`8`
- 扩展顺序：`A -> C -> D -> B -> E`

Open / Close 表变化：

| 步骤 | 当前扩展节点 | Open 表 | Close 表 |
| --- | --- | --- | --- |
| 1 | A | [C(f=6, g=4), B(f=8, g=1)] | [A] |
| 2 | C | [D(f=6, g=5), B(f=8, g=1)] | [A, C] |
| 3 | D | [B(f=8, g=1), E(f=8, g=8)] | [A, C, D] |
| 4 | B | [E(f=8, g=8)] | [A, C, D, B] |
| 5 | E | [] | [A, C, D, B, E] |

现象：

- 算法在第 1 步就优先选择了 `C`，没有先走代价更低的 `B`。
- 搜索方向明显被启发函数“带偏”，优先进入 `A -> C -> D` 分支。
- 最终找到的路径总代价为 `8`，比原始实验的最优代价 `7` 更大。

## 5. 行为变化分析

1. 原始启发函数下，`B` 的估计值较合理，因此 `f(B) = g(B) + h(B)` 较小，A* 会优先扩展 `B`。
2. 修改后把 `B` 的启发值从 `5` 提高到 `7`，导致 `B` 的 `f` 值变大；同时把 `C` 的启发值从 `5` 降到 `2`，导致 `C` 的 `f` 值明显变小。
3. 因为 A* 总是优先扩展 `f` 值最小的节点，所以搜索顺序从 `A -> B -> C -> D -> E` 变成了 `A -> C -> D -> B -> E`。
4. 修改后的启发函数对真实代价估计失真，尤其是对 `B` 的高估，使算法过早放弃了更优方向，最终先到达了总代价更高的路径。
5. 这说明 A* 的效率和最优性高度依赖启发函数质量。启发函数越接近真实剩余代价，搜索越高效；如果启发函数高估过多，就可能破坏最优性。

## 6. 结论

- 修改启发函数后，A* 的扩展顺序、Open 表变化和最终结果都发生了明显变化。
- 原始启发函数得到的路径代价为 `7`，修改后得到的路径代价为 `8`。
- 原因在于启发函数直接影响评估函数 `f(n)=g(n)+h(n)`，从而决定算法优先搜索哪个分支。
- 当启发函数不合理时，A* 虽然可能更快偏向某个方向，但可能失去最优解。
