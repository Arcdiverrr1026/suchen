# 机器学习实验5实验原理补充

## 二、实验原理

### 1. 支持向量机（SVM）

支持向量机（Support Vector Machine，SVM）是一种经典的有监督学习算法，主要用于分类任务。其基本思想是在特征空间中寻找一个最优分类超平面，使不同类别的样本尽可能被正确分开，并且让距离分类边界最近的样本到超平面的间隔最大。距离分类边界最近、对分类超平面位置起关键作用的样本称为支持向量。

在线性可分情况下，SVM 可以通过一个线性超平面完成分类：

```text
w·x + b = 0
```

其中，`w` 为权重向量，`x` 为样本特征，`b` 为偏置项。SVM 的目标是在保证分类正确的前提下最大化分类间隔，从而提高模型对未知样本的泛化能力。

实际数据通常并非完全线性可分，因此 SVM 引入惩罚系数 `C`。`C` 用于控制分类间隔和误分类样本之间的平衡：`C` 较大时，模型更重视训练样本的分类正确性，可能导致过拟合；`C` 较小时，模型允许一定误分类，分类间隔更大，模型泛化能力可能更强。

当样本在原始特征空间中难以线性分开时，可以使用核函数将样本映射到更高维空间，再在高维空间中寻找分类超平面。本实验中使用了线性核和高斯核（RBF 核）。线性核适用于类别边界较清晰、近似线性可分的数据；RBF 核适用于非线性分类问题，其表达式为：

```text
K(x_i, x_j) = exp(-gamma * ||x_i - x_j||^2)
```

其中，`gamma` 控制单个样本的影响范围。`gamma` 较小时，决策边界较平滑；`gamma` 较大时，决策边界更复杂，模型可能更容易过拟合。

本实验第一部分使用线性核 SVM 对鸢尾花数据集进行多分类，使用 RBF 核 SVM 对乳腺癌数据集进行二分类。模型效果主要通过准确率、F1 分数和混淆矩阵进行评价。准确率表示预测正确样本占总样本的比例；F1 分数综合考虑精确率和召回率；混淆矩阵可以直观展示各类别的正确分类与错误分类情况。

### 2. K-Means 聚类

K-Means 是一种经典的无监督聚类算法，用于根据样本特征之间的相似性将数据划分为若干个簇。与 SVM 不同，K-Means 在训练过程中不使用真实类别标签，而是根据样本之间的距离关系自动完成分组。

K-Means 算法需要预先指定簇数量 `K`，其基本步骤如下：

1. 随机初始化 `K` 个簇中心。
2. 计算每个样本到各个簇中心的距离，并将样本分配到距离最近的簇。
3. 根据每个簇内的样本重新计算簇中心。
4. 重复样本分配和簇中心更新过程，直到簇中心基本不再变化或达到最大迭代次数。

K-Means 的优化目标是最小化簇内平方误差：

```text
J = ΣΣ ||x_i - μ_k||²
```

其中，`x_i` 表示样本，`μ_k` 表示第 `k` 个簇的中心。目标函数越小，说明同一簇内样本越紧密。

由于 K-Means 基于距离计算，特征的量纲会直接影响聚类结果。如果某些特征数值范围较大，它们会在距离计算中占据更大权重。因此，本实验在进行 K-Means 聚类前，先对鸢尾花数据集特征进行标准化处理，使不同特征具有相近的尺度。

K-Means 的优点是原理简单、运行速度快，适合处理簇形状近似球形、簇数量较明确的数据；缺点是需要提前指定 `K` 值，并且对初始簇中心和异常点较敏感。本实验分别设置 `K=2`、`K=3`、`K=4` 进行聚类，并使用轮廓系数和 Calinski-Harabasz 指数评价不同 K 值下的聚类效果，同时与鸢尾花真实类别进行对比分析。

### 3. 密度聚类

密度聚类是一类基于样本分布密度进行聚类的方法，典型代表算法是 DBSCAN（Density-Based Spatial Clustering of Applications with Noise）。与 K-Means 不同，DBSCAN 不需要预先指定簇的数量，而是根据样本在空间中的密度分布自动发现簇，并能够识别噪声点。

DBSCAN 有两个重要参数：

- `eps`：邻域半径，表示以某个样本为中心向外搜索的范围。
- `min_samples`：邻域内形成核心点所需的最小样本数量。

根据这两个参数，DBSCAN 将样本点分为三类：

1. 核心点：在 `eps` 邻域内包含不少于 `min_samples` 个样本。
2. 边界点：自身不是核心点，但位于某个核心点的邻域内。
3. 噪声点：既不是核心点，也不属于任何核心点邻域的样本点。

DBSCAN 的聚类过程通常从核心点开始，将与核心点密度可达的样本不断扩展到同一个簇中。对于形状不规则的簇，DBSCAN 通常比 K-Means 更灵活；同时，它可以把离群样本识别为噪声点。

DBSCAN 的缺点是对参数 `eps` 和 `min_samples` 较敏感。`eps` 设置过小，可能导致大量样本被判定为噪声点；`eps` 设置过大，又可能把不同簇错误地合并到一起。`min_samples` 设置过大时，形成核心点的条件更严格，也可能增加噪声点数量。

本实验使用 DBSCAN 对标准化后的鸢尾花数据集进行密度聚类，通过调节 `eps` 和 `min_samples` 观察生成簇数量、噪声点数量和聚类效果的变化，并将 DBSCAN 聚类结果与 K-Means 聚类结果以及真实类别进行对比，分析密度聚类与基于距离的聚类方法之间的差异。
