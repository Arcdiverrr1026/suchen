# 任务3结果分析：K-Means 聚类

K-Means 在鸢尾花数据集上测试 K=2、K=3、K=4。按轮廓系数和 Calinski-Harabasz 指数判断，K=2 表现最好，轮廓系数为 0.5818，CH 指数为 251.35。

但如果使用真实标签进行对比，K=3 的 ARI 为 0.6201，高于 K=2 的 0.5681。这说明聚类内部评价指标和真实类别一致性并不完全一致。K=2 可能将 setosa 单独成簇，并把 versicolor 与 virginica 合并为一个簇，从距离结构上更紧凑；K=3 则更接近真实的三类标签。

因此，K-Means 的结果分析不能只看簇数量是否等于真实类别数，还需要结合轮廓系数、CH 指数、ARI 和可视化图综合判断。
