# 任务2结果分析：RBF 核 SVM 分类

RBF 核 SVM 在乳腺癌测试集上取得 Accuracy=0.9825、F1=0.9825。测试集中共 114 条样本，仅 2 条分类错误，其中恶性样本错分 1 条，良性样本错分 1 条。

与线性核 SVM 的 Accuracy=0.9737 相比，RBF 核略有提升。说明乳腺癌数据中的类别边界可能并非完全线性，RBF 核可以通过非线性映射获得更好的分类效果。

参数对比显示，C 和 gamma 过大时训练集准确率可能升高，但测试集准确率下降，存在过拟合风险。本次较优参数为 `C=1.0, gamma=scale`，兼顾训练效果和测试集泛化能力。
